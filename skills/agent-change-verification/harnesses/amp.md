# Amp adapter

Map the verification contract to the current Amp executor before running checks.

- Use shell commands for repository checks, `view_media` for screenshot/video/frame inspection, and direct file or remote read-back for external effects.
- Use a subagent only for independent verification that benefits from separate context; review its evidence yourself rather than trusting its summary.
- An orb does not include uncommitted local changes. Verify the checked-out revision and artifact identity before treating an orb result as evidence for local work.
- Use linked Amp threads as decision context only after reading their full content. Record thread URLs in the evidence bundle when they explain an acceptance criterion or external action.
- Keep evidence in the workspace or a durable artifact path. Do not rely on an executor's temporary console output as the only evidence.
